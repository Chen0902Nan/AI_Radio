# 03 · Fish 免费语音合成与本地音频缓存

Status: ready-for-agent
Type: task
Depends on: 01
Execution: done
确认依据：Q9 已整体确认；离线开发不依赖真实密钥，真实接入另见 07。

## 目标

将确定版本的串场文案转换为可通过同源地址播放的完整 MP3，固定免费模型，并让配置、超时、错误音频和缓存淘汰都有明确行为。输入：[语音契约](../contract.md)。

## 范围与输出

- 新建独立 Fish 适配和音频缓存模块；服务端读取密钥、`reference_id`，显式发送 `model: s2.1-pro-free`。
- 免费模型缺失/未知配置、缺少密钥/声音时不调用供应商；不容许省略 header 或失败后回退付费模型。
- 接收可取消的有界请求，检查 HTTP 状态、返回音频类型、长度上限、完整性和可取得的时长；错误 JSON/HTML 不能保存为成功 MP3。
- 收齐并校验后原子发布成品；缓存键包含文案、模型、音色和声音参数，返回成品 ID、路径/元信息，由 05 提供 HTTP 路由。
- 缓存 TTL 24 小时、活动目录上限 100 MiB，保护正在使用的成品；移入废纸篓完成淘汰，不自动清空废纸篓。清理不影响仍在读的音频。
- 为 05/06 返回时长及有效性；超过 30 秒不进入正式播报，短于 15 秒的有效基础介绍标注偏差，不能硬裁句尾。

## 验收

- 替身服务验证请求必带免费模型和正确声音；缺配置、401/402/429、超时、取消、响应中断、错误正文均不产生 ready 成品。
- 相同输入复用缓存，换音色/文案不复用旧声音；并发相同输入不写出半成品或重复发布。
- 容量、过期、当前播放保护和损坏缓存路径均有确定性验证；淘汰不会删除项目其他文件。
- 没有真实密钥也可完成模块和离线验收。真实普通话、免费准入和声音选择的证据由 07 补齐，不能用替身冒充。

## 边界

不直接修改路由或播放器，不新增付费 SDK/服务。需要依赖库时与集成人顺序修改包清单和锁文件；不自行扫描凭据存储或把密钥写入工单/日志。
