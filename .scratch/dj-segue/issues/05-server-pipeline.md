# 05 · 串场准备流水线与同源接口

Status: ready-for-agent
Type: task
Depends on: 02, 03
Execution: done
确认依据：Q9 已整体确认；按前置任务顺序交付。

## 目标

把目标歌曲校验、搜索文案、语音合成与任务状态串起来，以有限时间交付可播放成品，不阻塞现有补歌。输入：[接口及准备契约](../contract.md)、02/03 模块。

## 范围与输出

- 负责 `server/index.js`、`server/db.js` 集成及独立 DJ 协调模块；接入 prepare、job 查询、cancel、audio、主动试听 preview 路由。
- 准备请求验证会话、版本、目标身份；同一机会复用任务，相同键不同内容明确拒绝。每会话最多一条有效 DJ 流水线。
- 串行调用文案与 TTS，设置总截止时间及分阶段上限；过期/取消结果不重新激活任务，不影响更新机会。
- 同时校验目标完整音源；返回的 ready 成品携带完整媒体/目标身份和版本，不把音乐平台临时 URL 当永久可播保证。
- 分开记录文案失败、语音失败和歌曲失败，按契约冷却；没有免费语音配置时可提前返回 unavailable，避免每次白耗 Codex 额度。
- 现有会话停止、来源/编排更新与任务失效接通；配置用现有本地设置能力，密钥仍只在服务端。
- 提供独立数据库和替身依赖的服务端集成测试，避免触碰用户真实播放历史。

## 验收

- 正常任务从 preparing 到 ready，重复请求只生成一次；无效会话/旧版本/身份冲突均不能生成有效成品。
- 任一阶段超过上限或被取消，任务可回收且结果不会再被浏览器采用；新任务不会被旧任务 finally 清空。
- 认证/免费配置失败不发起循环调用；临时错误有上限冷却，音乐 `/api/queue/refill` 行为保留。
- 音频接口只返回本应用已完成成品，错误/缺失/过期音频有正确结果；读取中的音频受保护。
- 设置与任务状态不把播报写进歌曲反馈/播放记录；现有会话与选歌回归通过。
- 候选音色可在停止收听时通过 preview 试听，正式节目只用已确认音色；试听与节目任务分开，不能借试听开启付费模型或自动播放。

## 边界

网页仍拥有播放决定；不新增服务端播放调度、SSE 播放命令或持久化队列。可先按 01 使用替身搭接口，最终交付必须接通 02/03。
