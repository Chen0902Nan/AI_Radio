# 登录二维码错误修复

现场：仅 Vite 5173 监听；GET /api/login/qr 返回 502、0 字节，Nest 8787 无监听。登录页直接 res.json()，掩盖了服务连接失败。

计划：沿用已授权的真实 React 页面/外部 HTTP 测试边界，先在浏览器注入同样的空 502，断言显示连接失败且可重试；观察失败后修复登录请求的 HTTP 状态与响应格式检查，再验证重试成功以及正常二维码显示。二维码创建失败时不开始轮询。

不自动启动或重启用户服务。本轮解决错误呈现，实际连接恢复需要另一个终端启动 Nest。外部网易云响应使用 fixture，不声称真实扫码登录验收。

结果：浏览器空 502 回归先失败（Unexpected end of JSON input），检查 HTTP 状态后通过；空 200 回归先失败，解析失败转换为可读提示后通过。最终同一浏览器验证空 502、空 200、用户重试恢复并显示二维码通过。web 构建与类型检查通过。临时响应文件和 Chrome 配置移入废纸篓。
