```sh

npm run test:browser    # 构建后启动隔离 HTTP fixture + 临时无头 Chrome
```

应用回归通过生产 getRadioInstance、实际 PlaybackController/RefillController/SegueController 测试。仅 audio、时间及外部 HTTP/SSE 使用替身，没有 mock 内部控制器。React 展示验证实际渲染结果。HTTP 注入测试跨设置入口与消费入口，使用真实可播性检查逻辑。

隔离浏览器运行真实 React 产物和浏览器音频解码，覆盖歌曲→SSE 就绪 DJ→歌曲、补歌、暂停/恢复、停止后新会话及 Codex 计划不打断播放。使用本地生成 WAV、短时歌曲和模拟供应商响应，不代表网易云/Codex/Fish 真实接入验收。
