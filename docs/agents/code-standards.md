# 代码规范

适用于手写 TypeScript，包括组件、测试和工具脚本。

- **类型**：保持 `strict`，外部数据从 `unknown` 校验收窄；`any` 和强制断言仅限有明确依据的局部边界。
- **函数**：普通函数不超过 50 有效行、圈复杂度不超过 10、控制流嵌套不超过 3 层；优先提前返回，按职责拆分。
- **规模**：React 组件不超过 200 有效行，文件不超过 500 行。有效行不含空行、纯注释；JSX 计入组件和文件规模，生成代码除外。
- **解耦**：按职责和状态归属划分模块，接口小、依赖单向。视图与业务编排分开，业务逻辑不反向依赖视图或 HTTP 控制器；`packages/contracts` 不依赖框架和供应商客户端。
- **异步**：状态有唯一持有者；Promise 显式处理失败，订阅和定时器负责清理，过期请求的结果作废。

复杂度和行数目前仅作审查基准。超限时拆分或说明保留理由，避免为达标机械拆分、压行或增加转发层；已有代码仅治理本次修改涉及的职责。
